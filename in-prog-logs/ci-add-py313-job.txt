Task: add a Python 3.13 CI job to .github/workflows/tests.yml

Status: DONE -- PR opened, both jobs green, not merged.

What was done
-------------
1. Read .github/workflows/tests.yml first. The existing job is a matrix over
   `os` only ([ubuntu-latest, windows-latest]) with `python-version: "3.11"`
   hard-coded in setup-python. Chose a SECOND job over a `python-version`
   matrix axis, and the reason is in the YAML comment: adding a dimension
   would either (a) give the existing 3.11 pair a second, different install
   via `include:`, i.e. change the job that must not change, or (b) put 3.13
   on Windows too, which the task explicitly excludes for CI time. Two
   mirrored step lists is the smaller diff.
2. New job `test313`, name "ubuntu-latest / py3.13", runs-on ubuntu-latest
   (literal, no matrix), steps: checkout@v4, setup-python@v5 with
   "3.13", `pip install -e ".[dev]"`, `python -m pytest -q`. Same action pins
   as the existing job. Plain `pip install -e ".[dev]"` -- no constraint
   file, no pins -- so it resolves whatever a fresh user install resolves.
3. No Ruff step in the new job, and said so in the comment: E9,F answers
   "is this change syntactically broken" for the same source the 3.11 job
   already linted; re-linting on a second interpreter tests ruff, not the
   suite.
4. changelog.d/ci-py313-job.added.md, following changelog.d/README.md
   (slug.category.md, bullets, no headings, wrapped like its neighbours).
   Category `added`: a second interpreter in CI is a new capability. There
   was deliberately no fragment for the original tests.yml, so this is the
   first CI-only entry; the user asked for one.

Why the pint claim in the comments is not from memory
-----------------------------------------------------
changelog.d/micro-sign-display.fixed.md (commit 6bb1363, HEAD) already
records it: pint spells micro as U+00B5 up to 0.25 and U+03BC from 0.26 on,
and 0.26 is the first pint installable on Python 3.12+. Confirmed
independently that the local 3.13 venv has Pint 0.26.1, i.e. the 3.13 CI job
will in fact resolve the newer character.
