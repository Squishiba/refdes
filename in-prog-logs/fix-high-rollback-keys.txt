back.". Line drift: on this checkout the handler is revise.py:1642-1646,

     reference(s) while loading)", both dec files now `REQ-001@ajtez6xsfyg`.

     lands before the refusal), then `refdes revise mapping.yaml`:

     refused:
       cannot write items/dec_b.md (read-only tree?) -- no item file was
       rewritten and no hash was carried forward, so the tree is exactly as
       it was found. Make the tree writable and run it again.
       rolled back.
     revise exit=1
