Why the ruff gate is scoped to E9,F
-----------------------------------
AGENTS.md records that `ruff check .` has ~99 pre-existing findings, so an
unscoped run is not a usable gate. E9 (syntax errors) + F (undefined names,
unused imports, redefinitions) is the "actually broken" subset.
