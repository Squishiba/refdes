  options), added to NON_SCALAR_FIELD_TYPES, declared on log with

  style (_field_error): row-not-a-mapping shape error (options posture),
  id must be a non-empty string when given + unique within the list, state
  when given must be one of open/done/dropped (did-you-mean hint like the
  enum branch). Missing id/text/state not an error (matches options' posture
  and the plan's stated scope).
