Fix EDITOR-DRAFT-003 — corrupt draft mirror silently read as clean

Branch: fix/draft-corruption-recovery-20261013, off main 8b6a52e.

Finding (in-prog-logs/current-main-resweep-editor-drafts.tsv):
drafts.js load() wrapped sessionStorage.getItem and JSON.parse in one try;
a truncated/corrupt mirror fell into the same catch as a private-mode
storage failure and silently returned emptyDraft(): isDirty false, no
prompt on close, zero console output -- unsaved work indistinguishable
from no work. Reproduced against HEAD with a node probe
(.scratch/fix-editor-draft-003/probe.mjs): empty draft, prompted false.

Fix (src/refdes/serve/static/drafts.js only):
- Split the one try in load() into three: a blocked storage read (still
  the silent persistence-cost path -- nothing can be read OR preserved),
  a JSON.parse failure, and a mirror that parses but is not a draft
  object (null / array / scalar). The last two are corrupt mirrors.
- New reportCorruptMirror(): keeps the raw bytes + reason in a module
  Map, copies the bytes to sessionStorage key refdes.draft.corrupt.v1.<handle>
  (a key nothing else ever writes, so a reload or an edit never destroys
  it), logs a console.warn, and appends a visible 'banner bad' notice
  naming the recovery key with an explicit Discard button.
- hasAnyDraft() is true while any mirror is corrupt, so beforeunload
  keeps asking: preserved evidence counts as unsaved work.
- New exports corruptDraft(handle) / discardCorruptDraft(handle);
  discarding is the only release.
- If even the recovery copy fails (storage throws), the bytes stay in
  the page and the warn/banner/prompt still fire: persistence may be
  lost, silence never is.
