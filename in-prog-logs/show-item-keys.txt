DESIGN DECISIONS
- ls --keys: opt-in column between id and type (`ID  KEY  TYPE  ...`).
  Empty cell = blank padding, matching ls's own workspace-column style
  (cli.py cmd_ls docstring: "" printed as blank padding, not a
  placeholder) -- the task allows empty OR "-", blank is ls's style.
  When NO row has a key (cold --no-write project) key_w is 0 and the column
  vanishes: ls's zero-width rule for the board/workspace columns, so
  `--keys` there is byte-identical to the plain listing.

  THIS door only (cmd_thread), because threads_projection is the shared
  answer the index payload and the task pane read as string labels
  (test_threads_projection.py pins that shape); the projection itself is
  untouched, so `index`'s threads[].entries and the pane keep their bytes.

  and doesn't break the layout"): the header line is the only place thread
  prints entry labels (chain for one tip, tips for a fork), so the

  one line, no layout change below it. _thread_header is shared with
  `refdes work`, which has no flag, so it passes keys=None and keeps the
