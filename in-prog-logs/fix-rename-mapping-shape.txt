## Fix

revise.py: new `_shape_name` + `_section_as_dict` helpers just above
`mapping_from_dict`; every section is read through `_section_as_dict`, which
refuses a non-mapping section value with SchemaError naming file + section +
expected shape; `fields:` additionally checks each per-type entry is a mapping
and names the offending type. `raw.get(section) is None` (an empty section
header, `types:`) keeps its old "treated as empty" behavior. Deliberately NOT
reformatting surrounding code (PR #273 also touches revise.py).

Behavior note: a `fields:` type entry that is `null` (e.g. `bound:` with
nothing under it) used to load as an empty per-type rename dict; it is now a
named error, consistent with "fields: must map a type name to a mapping".
