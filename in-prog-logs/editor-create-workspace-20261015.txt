## Bug found while wiring the control (pre-existing, same lines)

`el('option', null, '(file default)')` sets no `value`, and a browser reports
an option's value as its text. The untouched Board select therefore sent
`fields.board = "(file default)"` -- truthy, past the `if (boardSelect.value)`
guard -- and the registry gate refused *every* create on any project that
declares boards. Reproduced live at base (422, above). Fixed in the same
stroke: placeholder value `''`, registry options carry explicit values; the
new Workspace select is built the same way from the start. The node harness
asserts the placeholder's value and the untouched create body (red at base:
`untouchedCreateFields == {"board": "(file default)"}`).
