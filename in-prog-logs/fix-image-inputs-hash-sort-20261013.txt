  no image diagnostics. Matches the TSV evidence exactly.

Fix (src/refdes/build.py, in _image_inputs_hash_value):
  Sort with a total-order key that never compares None with str:
    sorted(([path, digest] for ...), key=(path, digest is not None, digest or ""))
  For all-str-digest sets the key reduces to the plain (path, digest) pair
  comparison (second component constant True), so ordinary projects hash
  byte-identically; the None sentinel takes a deterministic slot (before
  any digest on the same path). Output shape unchanged (list of
  [path, digest-or-None] lists, still feeds _hash_payload["images"]).
