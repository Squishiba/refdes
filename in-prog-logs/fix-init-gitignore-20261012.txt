What was done

- src/refdes/scaffold.py: new `read_existing_gitignore(target_dir)`.
  Returns the file's text, or `None` when absent; raises `SchemaError`
  for the three documented shapes — lexists-but-not-a-regular-file
  (directory, symlink-to-directory), unreadable (`PermissionError`),
  non-UTF-8 (`UnicodeDecodeError`). `SchemaError` is already init's
  refusal channel (`init` raises it for existing config / bad preset)
  and `main()` prints it as `configuration error: ...` at exit 2 —
  which docs/cli-reference.md line 14 documents as the configuration
  error code, so no new exit-code surface.
- `scaffold.init` now calls the preflight BEFORE `os.makedirs`/the
  config write, so a refused init creates nothing — the transactional
  guarantee lives in the library, not just in the CLI's ordering.
- src/refdes/cli.py `cmd_init`: the announcement pre-read of
  `.gitignore` (the old raw `textio.read_text`) is replaced by the
  same preflight call, so shapes 1-2 refuse at the CLI's first
  filesystem touch too, and the preflight read doubles as the
  announcement's "before" text (no second read added).
- tests/test_scaffold.py: four new tests — non-UTF-8, unreadable
  (chmod 000, POSIX-only skipif copied from
  test_citation_path_hygiene.py's proven pattern), directory shape
  incl. "same dir inits cleanly after `rmdir`", and a library-level
  test that `scaffold.init` itself (not just cmd_init) refuses before
  creating anything.
