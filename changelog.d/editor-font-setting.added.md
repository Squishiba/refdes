**Browser font settings for the body editor** (`in-prog-logs/editor-format-toolbar-design-20261029.md`, slice 3). The editor now has a font control above the body textarea for choosing the font family, size, and line height used while editing. The preference is per browser in `localStorage` under `refdes.editor.font`, with a JSON shape of `{family, size, lineHeight}`; missing, invalid, and private-storage failures fall back to the defaults instead of throwing. The change is applied to the textarea through CSS custom properties only, so the saved body text, preview, and project settings remain untouched.
