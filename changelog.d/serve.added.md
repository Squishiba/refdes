- `refdes serve` starts a loopback-only local server (`127.0.0.1`, ephemeral port, per-launch token on every read and write, Host/Origin checks, CSP) that serves the rendered site as a preview from an OS temp directory — never `_site/` — with an "Edit" toolbar injected into the HTTP response only, and picks up edits made outside the browser by content-hash polling. Loading is side-effect-free: nothing is minted, expanded, or sealed. The editor application itself lands in later releases.
