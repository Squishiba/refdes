- `refdes serve` gained the editor's read side: `GET /api/items` answers a filtered item list from the *built* project — type, board, workspace, tag, source file, coverage stage, check state, blocked state, link relationships (`links_to`, `linked_from`, and the empty-required-verb query `missing_verb`), and free text over title and tags, all combinable, each facet value counted (cross-filtered), the whole filter held in the URL query — and `GET /api/item/<ref>` returns one item's fields, body, links in both directions, coverage, checks, diagnostics, and seal state. A bad filter value is a 400, never a silently-empty list. The `/edit/` shell is now the editor's front door: a filter sidebar, the item list, and a read-only item view with the rendered preview alongside.
