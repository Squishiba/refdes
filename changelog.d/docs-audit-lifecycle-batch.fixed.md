A real stamped baseline records the standard pinned at stamp time, and each entry also carries `hash_format`, `key`, and — where they apply — `verdict`, `calc_hash` and `calc_refs`. The "assembly, not new machinery" sentence listed only the first three values.
- Docs: the `removed` line in `lifecycle.md`'s `refdes audit` transcript was double-quoted. The printer uses Python `repr`, so a title with no embedded quote renders in single quotes.
- Docs: the quoted "`conforms_to` must be a list of group ids" configuration error in `multi-board.md` ended with `write conforms_to: [GRP-DBG]`, echoing the value just rejected. The message is fixed text ending `[GRP-001]`.
- Docs: `schema-reference.md` opened by claiming to cover every key in `refdes-project.yaml` but omitted `equations:` from its top-level block — the one block key of the ten it left out. It is a real, separately-validated key, and `math.md` and `troubleshooting.md` already document it.
