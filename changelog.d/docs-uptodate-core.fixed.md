- `docs/getting-started.md` now says `.refdes/schema.json` is regenerated by
  every command that loads the items tree, not every command that loads the
  project: `refdes new` and `refdes schema` read the config without writing
  `.refdes/`.
- `docs/getting-started.md` no longer says `check_severity`'s `default:` is
  always required. It is required only when the mapping leaves a declared
  status unlisted; a mapping that names every status loads without one (the
  bundled `component` mapping already does).
- `docs/concepts.md` and `README.md` no longer say `timeline` and `ignore` are
  indistinguishable in every observable way. A captured history-backed log
  entry digests every field, so a `timeline` change on one surfaces as the
  "edited after captured" warning.
- `docs/concepts.md` no longer says "No server". `refdes serve` is an optional
  local preview and browser editor; the built site is still static HTML.
- `docs/authoring.md` now lists the field types the build actually enforces
  (`enum`, `date`, `limit`, and the collection types `list`, `options`,
  `checks`, `citations`, `tasks`, plus `required:`/`required_when:`), not just
  `enum`, `limit`, and `citations`.
- `docs/authoring.md` no longer says folders under `items/` carry no meaning
  unconditionally: once `boards:` is registered, the first path segment is the
  board.
- `docs/ids.md` no longer shows a `need` type in its `refdes ls` retired-id
  sample (`need` is not a bundled type); the sample now uses `requirement`.
- `docs/links.md` now names every command whose writable load mints keys and
  expands bare references, including `thread`, `work`, `navis`, and
  `history capture`/`redact`/`migrate-seals`, and notes that `serve`'s load is
  side-effect-free. It also says the thread chain behaviour shipped, not that
  it will ship.
- `docs/markdown.md` no longer lists `body` among the plain-text field values;
  an item's body is markdown and renders as such.
- `README.md` adds `refdes serve` to the everyday command list and points at
  the browser editor guide.
