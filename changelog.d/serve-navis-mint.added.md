- `refdes serve` now answers `POST /api/navis/mint` with a JSON object body (`{}`; the mint is project-wide, extra keys are ignored): every keyless live marker gets a minted key, and the response reports each minted marker (`minted`: `key`, `key6`, `item`, `file`) and the markers this call refused (`still_keyless`). Refusals are JSON: 403 on a `--no-write` server, 400 on a body that is not a JSON object, 500 on a write failure. A successful mint rebuilds the preview before the response lands.
