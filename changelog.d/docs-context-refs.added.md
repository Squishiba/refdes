- Added `tools/docs_context/refs.py`, a maintainer-only tool (not shipped in the package) that parses a docs page with the site's own markdown parser and prints one JSON object of fact cards for every code ref, file ref, `refdes` command and link the page makes; it is strictly read-only, refuses paths that escape the repo before opening them, and runs a command's `--help` as a list argv only when refdes's own argparse accepts the verb path.
