- `refdes id` now replaces a numeric `id:` hint in place instead of adding a second `id:` line above it, wherever in the item it sits. A hint written under `type:`/`title:` — the ordinary shape for a hand-written item — was missed by the old single-line check, so the expanded id landed above a quoted `id: '007'` that YAML then read last: the item reloaded as `007`, `check` reported `id: 007 has no prefix yet`, and a second `refdes id` refused it as a burned-number collision. Applies to Markdown front matter and YAML list entries, block and flow style, and to a bare `id:` placeholder the same way.
- `refdes id` no longer converts a CRLF item file to LF. The file is read back in text mode, which had already rewritten every CRLF before the line-ending style was chosen, so a one-line id write-back silently rewrote the whole file's line endings. The hint's own line is now the only line that changes.
