- Improved CLI start-up by building the pint unit registry lazily (on first calc) instead of at import. Commands that never evaluate units — `ls`, `schema`, `keys`, `id`, `init`, `new`, `revision`, `history`, `navis`, `index` — no longer pay for it: measured on this repo's own project, `refdes --version` 738 ms → 244 ms and `refdes schema` 789 ms → 272 ms (median of 7 runs); the first calc in a process pays the registry build (~220 ms: pint import + registry construction) once, and calc-heavy builds measured no net regression (docs-site build 3027 ms → 2539 ms). Rendered sites, item output, and unit diagnostics are byte-identical.
